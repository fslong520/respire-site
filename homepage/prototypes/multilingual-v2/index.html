05 ENCRYPTED SYNC ⛨

Sync can use the cloud.
Plaintext does not have to.

When you need multiple devices,
rsrs syncs encrypted data.

Content, titles, tags, projects, and related data are included in the encrypted payload.

Keys are generated and held on the user’s side.

The server stores ciphertext.The server does not need to understand your memories.
