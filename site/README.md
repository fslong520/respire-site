# Website Output

Website source lives in [`../homepage/`](../homepage/README.md).

| Path | Purpose |
| --- | --- |
| `dist/client/` | Production website built by `homepage` |
| `dist/preview/` | Development preview built by `homepage` |
| `.openai/hosting.json` | Existing static hosting configuration |

Run the build and verification commands from `homepage/`. This directory contains no separate UI application.
